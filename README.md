FAST API : 
A simple Task Management REST API built with Python and FastAPI, demonstrating request body validation using Pydantic schemas.

🚀 Overview
This project is a learning exercise that walks through the fundamentals of building a REST API:

✅ Creating routes (GET, POST, PUT, DELETE)
✅ Working with request bodies
✅ Validating incoming data with Pydantic
✅ Designing schemas (Create, Update, Response)
✅ Auto-generated API documentation
🛠️ Tech Stack
Tool	Purpose
Python 3.10+	Programming language
FastAPI	Modern async web framework
Pydantic	Data validation and settings management
Uvicorn	ASGI server to run the app

⚙️ Setup & Installation
1. Clone the project & navigate into it
cd task-api
2. Create & activate a virtual environment
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate
3. Install dependencies
pip install fastapi uvicorn
4. Run the server
uvicorn main:app --reload
The API will be available at: http://127.0.0.1:8000

🧪 Example Requests
✅ Create a Task (Valid)
curl -X POST http://127.0.0.1:8000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Buy groceries",
    "description": "Milk, eggs, bread",
    "priority": "high",
    "category": "shopping"
  }'
Response: 201 Created

❌ Missing Title (Invalid)
curl -X POST http://127.0.0.1:8000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{}'
Response: 422 Unprocessable Entity

{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "title"],
      "msg": "Field required"
    }
  ]
}
❌ Title Too Short
-d '{"title": "ab"}'
Response: 422 — "String should have at least 3 characters"

❌ Invalid Enum Value
-d '{"title": "Test", "priority": "urgent"}'
Response: 422 — "Input should be 'low', 'medium' or 'high'"

✅ Get All Tasks
curl http://127.0.0.1:8000/api/tasks/
✅ Update a Task (Partial)
curl -X PUT http://127.0.0.1:8000/api/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"completed": true}'
✅ Delete a Task
curl -X DELETE http://127.0.0.1:8000/api/tasks/1
🎓 Concepts Learned
1. Schemas
Pydantic models that define the shape of valid data, separated by use case:

TaskBase — shared fields
TaskCreate — what the client sends
TaskUpdate — partial updates
Task — what the API returns
2. Validation
FastAPI automatically validates request bodies against the schema:

Type checks — int, str, bool, datetime
Constraints — min_length, max_length
Enums — restrict values to a fixed set
Optional fields — allow partial updates
Auto error responses — 422 with detailed messages
3. Request Body
The @router.post("/") handler receives validated, parsed data — no manual checks needed:

def create_task(task_data: TaskCreate):  # Already validated ✨
    ...
4. Partial Updates
Using model_dump(exclude_unset=True) to update only the fields the client sent:

update_fields = task_data.model_dump(exclude_unset=True)
